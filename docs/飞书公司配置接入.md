# 飞书公司配置接入

本公司使用三项飞书资源作为报价引擎的私有配置与留档入口：

| 环境变量 | 飞书资源 | 当前状态 |
|---|---|---|
| `EXPORT_QUOTE_RULES` | [公司规则包](https://tdar7qsr83.feishu.cn/docx/FC66dkiFnopKrxx7HUAcvz8Fn4f) | `pending`，未批准前会阻止正式加载 |
| `EXPORT_QUOTE_STORE` | [报价快照库](https://tdar7qsr83.feishu.cn/drive/folder/BPxbfMtQHlpMSdd68WwcLKJknsc) | 可用于上传快照 |
| `EXPORT_QUOTE_MOSS_MAPPING` | [MOSS 字段映射](https://tdar7qsr83.feishu.cn/docx/IYcPd21JTopANxx7QZvcLytZnKd) | `pending`，只读字段已部分核验 |

## 前置条件

电脑需要安装 `lark-cli`，并且当前使用者已经用自己的飞书账号登录。先检查：

```bash
lark-cli --version
lark-cli auth status
```

使用 `user` 身份时，能否读取规则或上传快照取决于该员工在飞书里的实际权限。引擎不会保存飞书 access token，也不会把个人凭证写进 GitHub。

## 调用行为

### 规则包

每次 `validate_quote`、`screen_funders` 或 `calculate_quote` 调用都会读取飞书文档中包含 `schema_version` 的 JSON 代码块。规则包必须满足：

- `status=confirmed`
- 存在 `approved_by` 和 `approved_at`
- 每项启用规则自身也是 `confirmed`

当前公司规则包还是 `pending`，因此测试读取会成功，但正式计算会明确返回“规则包尚未经负责人确认”。系统不会退回公开样例或使用模型猜测的价格。

### 报价快照

计算完成后，引擎先在 `~/.export-quote/quotes` 保存权限为仅当前用户可读写的不可变 JSON，再上传到飞书快照文件夹。同一结果哈希通过本地上传标记避免重复上传；上传失败不会删除本地快照，下次可以重试。

### MOSS 映射

调用 `export_moss` 时会读取飞书映射文档中的 JSON。当前只生成可复制填写包，不自动打开、填写或提交 MOSS。

## 常见问题

**提示未找到 lark-cli**  
先安装并完成飞书登录，再重新启动 MCP 客户端，使它能读取更新后的 PATH。

**提示没有权限或登录失效**  
用同一台电脑执行 `lark-cli auth status`，确认登录账号，并在飞书中检查对应文档或文件夹权限。

**提示规则包未经确认**  
这是当前候选规则的正确状态。业务负责人确认数值、适用范围和有效期后，需要按规则审批流程发布新的 `confirmed` 版本。

**飞书不可用时会不会继续计算？**  
不会。使用飞书 URL 配置后，读取失败会明确终止，不会静默采用缓存、公开样例或旧规则。
